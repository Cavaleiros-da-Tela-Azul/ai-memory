# Conceitos e Domínio (`concepts/`)

Esta pasta contém o **conhecimento conceitual** sobre os projetos da equipe:

* **Modelagem de Domínio:** Entidades centrais do negócio (ex.: `Usuario`, `Transacao`, `Tenant`).
* **Arquitetura de Sistemas:** Visão geral de como os módulos e serviços interagem.
* **Glossário:** Termos técnicos e jargões específicos do negócio.

Ao documentar conceitos aqui, os agentes de IA entenderão a semântica do projeto em vez de apenas o código bruto.
