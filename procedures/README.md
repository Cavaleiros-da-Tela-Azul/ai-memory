# Procedimentos e Guias (`procedures/`)

Esta pasta armazena **rotinas operacionais padrão (SOPs)**, guias e receitas de desenvolvimento:

* Como configurar o ambiente de desenvolvimento local.
* Processos de build, migração de banco de dados e execução de testes.
* Rituais de deploy e pipelines de CI/CD.
* Resolução de incidentes recorrentes.

Instruções documentadas aqui garantem que qualquer desenvolvedor ou agente de IA execute os passos sempre da mesma forma consistente.
