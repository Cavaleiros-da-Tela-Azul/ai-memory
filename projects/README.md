# Projetos da Organização (`projects/`)

Espaço reservado para manter a memória isolada de cada projeto ou microsserviço da organização **Cavaleiros da Tela Azul**, caso opte-se por centralizar múltiplos projetos neste mesmo repositório de memória.

---

## 📁 Estrutura por Projeto
Cada projeto pode replicar as pastas temáticas:

```text
projects/
├── backend-api/
│   ├── _rules/
│   ├── decisions/
│   └── gotchas/
└── frontend-app/
    ├── _rules/
    ├── decisions/
    └── gotchas/
```
