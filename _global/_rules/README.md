# Diretrizes Globais da Organização (`_global/_rules/`)

As regras nesta pasta possuem escopo **universal**. Elas se aplicam a **todos** os projetos e workspaces mantidos pelos Cavaleiros da Tela Azul.

Enquanto a pasta `_rules/` raiz pode conter regras gerais do repositório, esta seção é voltada para padrões organizacionais transversais, como:

* Padrões de segurança corporativa.
* Políticas de licença de dependências de terceiros.
* Convenções institucionais de documentação e revisão por pares.
