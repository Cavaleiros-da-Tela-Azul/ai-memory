# Decisões de Arquitetura (`decisions/`)

Esta pasta armazena os **Architecture Decision Records (ADRs)** da equipe.

Sempre que uma decisão técnica relevante for tomada (ex.: escolha de banco de dados, protocolo de autenticação, refatoração estrutural, adoção de biblioteca), ela deve ser documentada aqui.

---

## 📄 Formato Recomendado
Adote a convenção de nomenclatura sequencial ou por data:
* `YYYY-MM-DD-titulo-da-decisao.md` ou `0001-titulo-da-decisao.md`

Consulte o arquivo [[adr-template|adr-template.md]] para criar novas decisões.
