# Armadilhas e Gotchas (`gotchas/`)

O catálogo de **problemas conhecidos, bugs sutis e armadilhas** (*gotchas*).

Quando um desenvolvedor ou agente gastar horas resolvendo um erro não óbvio (ex.: incompatibilidade de versão de biblioteca, bug em ambiente Windows, comportamento inesperado de um framework), registre aqui:

---

## 📝 Formato Recomendado
* **Sintoma:** O que acontece (mensagem de erro ou comportamento estranho).
* **Causa Raiz:** Por que o erro acontece.
* **Solução / Contorno:** Como resolver ou contornar o problema.

Dessa forma, o `ai-memory` impedirá que outros agentes ou colegas de equipe caiam na mesma armadilha novamente.
